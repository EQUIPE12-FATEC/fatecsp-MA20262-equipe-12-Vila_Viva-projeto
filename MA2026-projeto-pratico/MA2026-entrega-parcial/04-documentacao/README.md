# 📚 04 — Documentação \| Processos e Evidências

## 📌 Objetivo

Este diretório reúne os **relatórios técnicos** que explicam como as bases foram tratadas, automatizadas, verificadas e analisadas no projeto Vila Viva. A documentação permite compreender as decisões tomadas e reproduzir as etapas com maior segurança.

## 📄 Documentos

| Documento | Conteúdo |
| :---- | :---- |
| `Documentacao_01_Manual.pdf` | Tratamento por fórmulas no Excel, organização das abas, auditoria e pendências. |
| `Documentacao_02_Power_Query.pdf` | Consultas M, parâmetros, transformação, atualização e comparação com o Excel manual. |
| `Documentacao_03_PowerPivot.pdf` | Organização das quatro visões, indicadores, interpretação e limitações da análise. |

## 🧭 Como utilizar

Comece pelo relatório **Manual** para entender as fontes e as regras de cálculo. Em seguida, consulte o **Power Query** para acompanhar como essas regras foram automatizadas. Por fim, leia o **PowerPivot** para interpretar os resultados analíticos e identificar os cuidados necessários.

## ✅ Importância para a qualidade

A documentação contribui para:

- **Rastreabilidade:** identificação das fontes e dos procedimentos.  
- **Reprodutibilidade:** entendimento das transformações e fórmulas.  
- **Validação:** registro de comparações, testes e resultados.  
- **Transparência:** apresentação de limitações e pendências.  
- **Manutenção:** orientação para futuras atualizações e revisões.

> **Importante:** documentação técnica não substitui validação epidemiológica por profissional responsável e não comprova, sozinha, a conclusão de todos os componentes de um modelo Power Pivot.
