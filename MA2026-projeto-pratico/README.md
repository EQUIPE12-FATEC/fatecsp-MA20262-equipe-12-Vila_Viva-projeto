# 🏘️ Programa Vila Viva \| Projeto Prático

**Fatec São Paulo · Microinformática Aplicada (ILP590) · Equipe 12 · 2026**

## 📌 Sobre o projeto

O **Programa Vila Viva** é um projeto acadêmico de organização e análise de dados epidemiológicos municipais, com foco em **COVID-19, dengue e pneumonia**. A proposta é transformar planilhas de origem em informações estruturadas que auxiliem a leitura territorial, a identificação de necessidades de saúde e o planejamento de ações de Atenção Primária.

O trabalho contempla dados de **2022 a 2025**, organizados por município e ano. As três bases representam indicadores diferentes e são analisadas separadamente para evitar comparações inadequadas.

## 🎯 Objetivos

- Organizar e conferir registros epidemiológicos municipais.  
- Aplicar fórmulas do Excel ao tratamento inicial dos dados.  
- Reproduzir transformações com **Power Query**, favorecendo atualizações.  
- Produzir análises e visualizações a partir dos dados preparados.  
- Documentar procedimentos, limitações e verificações de qualidade.

## 🧰 Ferramentas

`Microsoft Excel` · `Power Query` · `Power Pivot (etapa analítica)` · `Git/GitHub` · `Documentação técnica`

## 🔄 Etapas do trabalho

| Etapa | Finalidade |
| :---- | :---- |
| Excel | Inspeção das fontes, tratamento manual por fórmulas e auditoria. |
| Power Query | Conexão às planilhas, transformação automatizada e conferência das saídas. |
| Power Pivot / análises | Organização de visões executiva e por doença; evolução do modelo analítico. |
| Documentação | Registro das regras, evidências, resultados e pendências. |

## 📂 Organização

A entrega parcial está organizada em [`MA2026-entrega-parcial`](../MA2026-entrega-parcial/), com um README específico para cada etapa.

## ⚠️ Limitações

Os registros de COVID-19 incluem pendências de validação da fonte oficial. Na versão de origem de pneumonia, há campos de internações e população não preenchidos. As visualizações não devem ser interpretadas como comprovação automática de um modelo Power Pivot completo com relacionamentos e medidas DAX.
